# Password Strength Visualizer

## 概要
パスワードの強度を視覚的に表現する対話型ツールです。入力されたパスワードの複雑さを分析し、美しいパーティクルアニメーションで強度を表現します。

## 機能
- **リアルタイム強度分析**: 入力と同時にパスワード強度を評価
- **視覚的フィードバック**: パーティクルアニメーションで強度を表現
- **詳細な要件チェック**: 5つの基準でパスワードを評価
- **パスワード表示切替**: 入力内容の確認が可能
- **セキュリティヒント**: 強度に応じた改善提案
- **レスポンシブデザイン**: モバイル・デスクトップ両対応

## パスワード評価基準
1. **文字数**: 8文字以上
2. **大文字**: A-Zを含む
3. **小文字**: a-zを含む
4. **数字**: 0-9を含む
5. **特殊文字**: !@#$%^&*などを含む

## 強度レベル
- **弱い** (赤): 基本的な要件を満たしていない
- **普通** (オレンジ): 最低限の要件を満たす
- **良い** (黄): 複数の要件を満たす
- **強い** (緑): ほとんどの要件を満たす
- **非常に強い** (青紫): すべての要件を満たし、十分な長さ

## 視覚化の特徴
- パーティクルの数と動きがパスワード強度に連動
- 強度が高いほど粒子が活発に動き、接続線が増加
- カラーグラデーションで直感的に強度を把握
- スムーズなアニメーションで変化を表現

## 技術仕様
- **Canvas API**: パーティクルアニメーション
- **CSS Transitions**: スムーズな UI 変化
- **正規表現**: パスワード分析
- **レスポンシブ対応**: タッチデバイス最適化

## セキュリティ考慮事項
- パスワードはクライアント側でのみ処理
- 入力内容は保存・送信されない
- 一般的なパターンの検出機能付き
