# Day 98: Hyper-Realistic 3D Experience

画面から飛び出してきそうなほどリアルな3D体験を実現する、最先端のWeb 3Dビジュアライゼーションです。

## コンセプト

このプロジェクトは、2D画面の制約を超えて、真の立体感を生み出すことを目指しています。複数の3D技術を組み合わせ、視差効果、被写界深度、リアルタイムライティングなどを駆使して、画面から飛び出すような錯覚を作り出します。

### 3D要素

1. **フローティングオブジェクト**
   - 透明なガラス質のキューブ
   - 発光する球体
   - 黄金のピラミッド
   - リアルタイムの回転と浮遊

2. **パーティクルフィールド**
   - 200個の3D空間パーティクル
   - 深度によるソート
   - グロー効果とコア表現
   - 有機的な動き

3. **立体視オーバーレイ**
   - 3層の深度レイヤー
   - 視差による奥行き表現
   - マウス追従による動的変化

4. **リアルタイムライティング**
   - 動的な光源
   - ボリュメトリックライト
   - ソフトシャドウ
   - 反射と屈折

## 技術的特徴

### 3D投影システム
```javascript
const perspective = 1000 / (1000 - z * zoom);
const x = centerX + (objX + parallaxX) * perspective;
const y = centerY + (objY + parallaxY) * perspective;
```

### 視差効果
- マウス位置による多層視差
- Z軸深度に基づく移動量
- スムーズな追従アニメーション

### 被写界深度
- 距離に応じたブラー効果
- フォーカスポイントの動的変更
- リアルなボケ表現

### 表示モード

1. **通常モード**
   - 標準的な3D表示

2. **アナグリフモード**
   - 赤青メガネ用の立体視
   - RGB分離による深度表現

3. **交差法モード**
   - 裸眼立体視用
   - 左右画像のオフセット

4. **VRモード**
   - WebXR対応（実験的）

## インタラクション

### マウス操作
- **移動**: 視点の変更と視差効果
- **スクロール**: ズームイン/アウト

### コントロールパネル
- **視差強度**: 立体感の調整
- **被写界深度**: ボケ効果の制御
- **ライティング**: 照明の明るさ

## 視覚効果

### リアリズムの要素
1. **物理的な光の挙動**
   - 光源からの距離による減衰
   - 表面での反射と散乱
   - 透明オブジェクトの屈折

2. **材質表現**
   - ガラスの透明感
   - 金属の反射
   - 発光体のグロー

3. **空間認識**
   - 正確な遠近法
   - オクルージョン
   - 大気遠近法

### パフォーマンス最適化
- Canvas 2Dによる軽量レンダリング
- 効率的なZソート
- レイヤー別の更新頻度制御

## 没入感の演出

1. **初期警告**: 3D効果の強さを事前に通知
2. **段階的な深度**: 手前から奥への自然な配置
3. **連続的な動き**: 途切れのないアニメーション
4. **環境光**: 全体を包む柔らかな照明

このプロジェクトは、Webブラウザで実現可能な3D表現の限界に挑戦し、画面の向こう側に別の空間が存在するかのような錯覚を生み出します。
