# Day 078: NotGPT - 人工無能チャット

ChatGPTのような見た目を持つ、シンプルなパターンマッチング型チャットボット（人工無能）です。

## 特徴

- ChatGPT風のモダンなUI
- キーワードベースの応答システム
- タイピングアニメーション
- レスポンシブデザイン（モバイル対応）
- ダークテーマ

## 応答カテゴリ

- 挨拶（こんにちは、おはよう等）
- 天気の話題
- プログラミング関連
- AI・人工知能の話題
- 食べ物の話題
- 質問への応答
- お礼
- お別れの挨拶

## 技術仕様

- 純粋なHTML/CSS/JavaScript（フレームワークなし）
- キーワードマッチングによる応答選択
- ランダムな応答遅延（1〜3秒）でリアル感を演出
