# Day 88: 無限を視覚化して

異なる種類の無限の概念を視覚的に探索できるインタラクティブなビジュアライゼーションです。

## 無限の種類

### 1. 数学的無限
- 無限級数（1/2 + 1/4 + 1/8 + ...）の視覚化
- 無限に続く螺旋
- 無限小への分割

### 2. フラクタル無限
- シェルピンスキーの三角形
- コッホ曲線
- 自己相似性による無限の複雑さ

### 3. パラドックス無限
- ゼノンのパラドックス（アキレスと亀）
- ヒルベルトのホテル（無限の部屋）
- 無限降下

### 4. 再帰的無限
- 再帰的な正方形構造
- ドロステ効果（画像の中の画像）
- 自己参照による無限ループ

### 5. 連続体無限
- カントール集合
- 実数直線の密度
- 連続関数の無限の点

## 操作方法

- **モード切替**: 上部のボタンで異なる無限の種類を選択
- **ズーム**: マウスホイール、ピンチ操作、または右側のボタン
- **移動**: ドラッグで視点を移動
- **リセット**: ⟲ボタンで初期状態に戻る

## 技術的な特徴

- Canvas APIを使用した動的な描画
- 各無限タイプに特化したアルゴリズム
- ズームレベルに応じた詳細度の調整
- 滑らかなアニメーションと遷移
- モバイル対応のタッチ操作
