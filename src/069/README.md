# 🧠 絵文字記憶ゲーム

## 概要
絵文字を使った楽しい記憶力ゲームです。表示される絵文字のシーケンスを覚えて、正しい順番でタップしてください！

## 特徴
- 🎮 **直感的な操作**: タップするだけの簡単操作
- 📱 **レスポンシブデザイン**: スマホ・PC両対応
- 🎯 **段階的難易度**: レベルが上がるごとに難しくなる
- 💡 **ヒント機能**: 困った時のお助け機能
- 🏆 **ハイスコア記録**: 最高記録を保存
- ✨ **美しいアニメーション**: 視覚的に楽しい演出

## ゲームルール
1. **スタート**ボタンを押してゲーム開始
2. 表示される絵文字のシーケンスを覚える
3. 同じ順番で絵文字をタップする
4. 正解するとレベルアップ！
5. 間違えるとゲームオーバー

## 機能詳細

### 🎯 レベルシステム
- レベル1: 3個の絵文字から開始
- レベルが上がるごとにシーケンスが長くなる
- 最大8個まで増加

### 💡 ヒント機能
- ゲーム中に最大2回まで使用可能
- 次にタップすべき絵文字を教えてくれる
- 使用するとスコアが50点減点

### 🏆 スコアシステム
- レベル完了時: レベル × 100点
- ヒント使用: -50点
- ハイスコアは自動保存

### 📱 モバイル対応
- タッチ操作に最適化
- 画面サイズに応じてレイアウト調整
- スクロール・ズーム防止機能

## 技術仕様
- **HTML5**: セマンティックなマークアップ
- **CSS3**: グラデーション、アニメーション、レスポンシブデザイン
- **JavaScript**: ES6+、ローカルストレージ活用
- **絵文字**: 32種類の多彩な絵文字を使用

## 使用絵文字
- 😀 表情: 8種類
- 🐶 動物: 8種類  
- 🍎 食べ物: 8種類
- ⚽ スポーツ: 8種類

- Firefox
- Safari
- Edge

## 遊び方のコツ
1. **集中力**: シーケンス表示中は集中して覚える
2. **パターン認識**: 絵文字の種類でグループ分けして覚える
3. **リズム**: 一定のリズムでタップする
4. **ヒント活用**: 困った時は遠慮なくヒントを使う
