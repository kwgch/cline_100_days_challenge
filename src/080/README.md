# Day 080: ウィキペディア偽 - 架空の百科事典

Wikipediaのような見た目で、完全にデタラメな内容の百科事典サイトです。

## 機能

- Wikipedia風の本格的なデザイン
- ランダムな架空記事の表示
- 記事内リンクのクリックで新しい架空記事へ遷移
- 検索機能（常に0件の結果）
- モバイル対応レスポンシブデザイン

## 収録記事例

- 量子チーズ理論
- 時空間トースト焼き機
- 透明インク症候群
- 逆重力ペンギン
- 感情色彩変換装置
- 円周率料理法

## 使い方

1. `index.html`をブラウザで開く
2. 記事内のリンクをクリックして他の架空記事を探索
3. 「おまかせ表示」で新しい記事をランダム表示
4. 検索ボックスで存在しない記事を検索

## 技術仕様

- 純粋なHTML/CSS/JavaScriptで実装
- 外部ライブラリ不使用
- レスポンシブデザイン対応
