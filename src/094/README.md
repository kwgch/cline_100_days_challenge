# Day 94: 始まりと終わりが同じ場所にあるもの

循環、回帰、永遠のループを探求するインタラクティブな体験です。始まりと終わりが一つになる様々な概念を視覚化しました。

## コンセプト

このプロジェクトでは、「始まりと終わりが同じ場所にある」という哲学的な概念を、8つの異なる視点から表現しています。

### 1. ウロボロス
- 自らの尾を食べる蛇のアニメーション
- 永遠の自己完結性の象徴
- 破壊と再生の無限サイクル

### 2. 人生の旅路
- 誕生→成長→絶頂→衰退→回帰の円環
- 各段階が自動的に移行
- 人生のサイクルを視覚的に表現

### 3. メビウスの輪
- 表と裏が繋がった一つの面
- 3D回転アニメーション
- 境界のない連続性の表現

### 4. 季節の円環
- 春夏秋冬の永遠の巡り
- 各季節の俳句表示
- グラデーション背景の変化

### 5. 円環の物語
- 始まりに戻る旅人の物語
- 8つの断章で構成
- 円形のプログレスバー

### 6. 回文生成器
- 前からも後ろからも同じ文字列
- リアルタイム回文生成
- 文字のアニメーション効果

### 7. 永遠の時計
- 12時間周期の循環
- 時間の哲学的メッセージ
- アナログ時計の視覚化

### 8. 無限螺旋
- 黄金螺旋のフラクタル描画
- 内へ外へ続く永遠の動き
- 数学的美しさの表現

## 技術的な実装

### JavaScript
- オブジェクト指向設計（CircularJourneyクラス）
- Canvas APIによる動的描画
- 周期的アニメーション
- DOM操作とイベント処理

### CSS
- グラデーションアニメーション
- 3D変形効果
- レスポンシブデザイン
- 円形レイアウト

### 数学的要素
- 三角関数による円運動
- パラメトリック方程式（メビウス）
- 黄金比螺旋
- 極座標系

## インタラクション

- **自動アニメーション**: 各要素が独立して循環
- **クリック操作**: 物語の進行、回文生成
- **スライダー操作**: 赤外線感度の調整
- **リセット機能**: 旅の追跡をリセット

## 哲学的な意味

このプロジェクトは、東洋哲学の「輪廻」、西洋の「永劫回帰」、そして現代科学の「循環システム」など、様々な文化や思想における循環の概念を統合しています。

すべての終わりは新たな始まりであり、すべての始まりはかつての終わりです。この永遠の循環の中で、私たちは常に同じ場所に戻りながら、決して同じではありません。
