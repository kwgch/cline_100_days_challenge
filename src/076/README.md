# Day 076: Emoji Catcher 3D 🎯

A fun 3D game where you catch falling emojis using Three.js!

## Features 🌟

- **3D Graphics**: Built with Three.js for smooth 3D rendering
- **Emoji Sprites**: Various emoji types with different effects
- **Dynamic Gameplay**: Difficulty increases with levels
- **Particle Effects**: Visual feedback when catching emojis
- **Mobile Support**: Touch controls for mobile devices

## How to Play 🎮

1. Move your basket left and right using mouse or touch
2. Catch the good emojis for points:
   - 🌟💎🎁🍎🍕 etc. = +10 points
3. Avoid the bad emojis:
   - 💣💀🕷️ etc. = -20 points and -5 seconds
4. Special emojis (after level 2):
   - 🚀⭐🔥 = +50 points and +10 seconds
5. Progress through levels as your score increases
6. Game ends when time runs out

## Game Mechanics ⚙️

- **Scoring System**: 
  - Good emojis: +10 points
  - Bad emojis: -20 points, -5 seconds
  - Special emojis: +50 points, +10 seconds
- **Level Progression**: New level every 100 points
- **Increasing Difficulty**: Emojis fall faster at higher levels
- **Time Limit**: 60 seconds initial time

## Technical Details 🛠️

- Three.js for 3D rendering
- Canvas-based emoji textures
- Collision detection system
- Particle system for visual effects
- Responsive design for all devices
