# 072 - 星空の舞 (Beautiful Starry Dance)

美しいパーティクルアニメーションによる星空のアート作品です。

## 特徴

- **動的パーティクルシステム**: 150個の星が美しく舞い踊る
- **インタラクティブ**: クリック/タップで新しい星を追加
- **4つのカラーテーマ**: 白、金、ピンク、緑の美しいグラデーション
- **レスポンシブデザイン**: スマホとPCの両方に対応
- **滑らかなアニメーション**: 60FPSの流れるような動き

## 技術的特徴

### パーティクルシステム
- 各パーティクルは独自のライフサイクルを持つ
- フェードイン・フェードアウト効果
- きらめき効果（twinkle）
- 自動的なリセットとリサイクル

### 視覚効果
- 放射状グラデーション
- パーティクル間の接続線
- 美しい背景グラデーション
- グロー効果とテキストアニメーション

### インタラクション
- マウスクリック/タッチで星を追加
- アニメーションの一時停止/再生
- カラーテーマの切り替え
- パーティクルのリセット

## 操作方法

- **クリック/タップ**: その位置に新しい星を追加
- **一時停止ボタン**: アニメーションの停止/再開
- **色変更ボタン**: カラーテーマの切り替え
- **リセットボタン**: すべての星をリセット

## スマホ対応

- タッチイベントによる画面スクロール防止
- レスポンシブなUI要素
- 最適化されたパフォーマンス

## 美しさのポイント

1. **色彩の調和**: 深い紫のグラデーション背景に映える星の色
2. **動きの美しさ**: 自然な軌道と速度変化
3. **光の表現**: グラデーションとグロー効果による光の演出
4. **インタラクティブ性**: 触れることで生まれる新たな美しさ

この作品は、デジタルアートとインタラクティブ技術を組み合わせて、見る人に癒しと美しさを提供することを目的としています。
