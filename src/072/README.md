# Day 072 - カーソルヒーロー

マウスカーソルが主人公となるアクションゲームです。

## ゲーム内容

- マウスカーソルを操作してプレイヤーキャラクターを動かす
- 金色の星を集めてスコアを獲得
- 赤い敵に触れるとライフが減少
- すべての星を集めると次のレベルへ進む
- レベルが上がると敵の数と速度が増加

## 操作方法

- **マウス**: カーソルを動かしてキャラクターを操作
- **タッチ**: 画面をタッチしてキャラクターを移動（モバイル対応）

## 特徴

- カーソルの軌跡が表示される
- パーティクルエフェクトでアイテム取得や衝突を演出
- レベルが上がるごとに難易度が上昇
- シンプルで直感的な操作性
