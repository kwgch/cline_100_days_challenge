# Day 99: Tactile Playground - 触感の遊び場

触るのが楽しくて止められない、インタラクティブな触感体験のコレクションです。

## コンセプト

このプロジェクトは、デジタルでありながら触覚的な満足感を提供する8つの体験を集めた「触感の遊び場」です。それぞれが異なる物理的な感触をシミュレートし、視覚・聴覚・（可能な場合は）触覚フィードバックを組み合わせています。

### 触感体験

1. **ぷるぷるスライム**
   - 弾性体シミュレーション
   - マウス/タッチで引っ張って遊ぶ
   - 自動的に元の形に戻る
   - ぷるぷるとした動き

2. **磁性流体**
   - 磁力に反応する流体パーティクル
   - マウスが磁石として機能
   - メタボール効果で流体感を表現
   - 黒い液体の不思議な動き

3. **無限プチプチ**
   - クリックで潰れるバブル
   - ポップ音の生成
   - 自動復活機能
   - ポップカウンター

4. **魔法の砂場**
   - 描く・消す・雨のツール
   - 重力シミュレーション
   - カラフルな砂粒子
   - 触った場所から砂が生成

5. **伸縮ゴムバンド**
   - ピン間でゴムバンドを張る
   - SVGフィルターでゴムの質感
   - 伸縮アニメーション
   - 接続時のスナップ効果

6. **きらきら粒子の滝**
   - マウス追従エミッター
   - 発光パーティクル
   - 重力に逆らって上昇
   - 幻想的な光の軌跡

7. **液体ボタン**
   - ホバーで液体が広がる
   - クリックで波紋エフェクト
   - 各色で異なる音
   - ぷるんとした触感

8. **音の波紋**
   - 音階ボタン（ド・レ・ミ・ファ・ソ）
   - 周波数に応じた色の波紋
   - 視覚化された音波
   - 重なり合う波の干渉

## 技術的特徴

### 物理シミュレーション
- バネ・ダンパーモデル（スライム）
- 磁力シミュレーション（磁性流体）
- 重力と空気抵抗（砂・粒子）
- 弾性変形（ゴムバンド）

### インタラクティブ要素
- マルチタッチ対応
- リアルタイムレスポンス
- 状態の永続性
- スムーズなアニメーション

### フィードバックシステム

1. **視覚フィードバック**
   - 即座の視覚的反応
   - 物理的に正確な動き
   - 美しいエフェクト

2. **聴覚フィードバック**
   - Web Audio APIによる音生成
   - 状況に応じた音の変化
   - 満足感のある効果音

3. **触覚フィードバック**
   - Vibration APIによる振動
   - 強度の調整（軽・中・重）
   - 視覚的な振動表示

### パフォーマンス最適化
- Canvas 2Dの効率的な使用
- 必要な部分のみの再描画
- パーティクル数の動的調整
- RequestAnimationFrameによる60fps

## 中毒性の要素

1. **即座の反応**: タッチした瞬間に反応
2. **予測可能性**: 物理法則に従った自然な動き
3. **バリエーション**: 8つの異なる体験
4. **進行要素**: ポップカウンターなどの記録
5. **探索性**: 各ツールの組み合わせ

## 操作方法

- **タッチ/クリック**: 基本的な操作
- **ドラッグ**: 連続的な操作
- **メニュー**: 下部のボタンで体験を切り替え
- **ツール**: 各体験固有のツール選択

このプロジェクトは、デジタル体験でありながら、実際に触っているかのような満足感を提供することを目指しています。シンプルな操作で無限に遊べる、究極の「いじりがいのある」アプリケーションです。
