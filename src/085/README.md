# Day 85: 不気味で中毒性のあるミニゲーム「見つめる」

目を見つめ続けることでスコアを稼ぐ、シンプルだが不気味なミニゲームです。

## ゲームルール

- **目を長押し**：画面中央の目を長押し（クリック/タッチ）して凝視する
- **凝視度を維持**：凝視し続けると凝視度が上昇し、スコアが増える
- **マルチプライヤー**：凝視度80%以上でスコア倍率が上昇
- **まばたき注意**：ランダムに目がまばたきし、凝視度が減少する
- **不気味な演出**：スコアが上がるほど画面に不気味な効果が追加される

## 中毒性の仕組み

- シンプルな操作で即座にプレイ可能
- 徐々に増える不気味な演出が好奇心を刺激
- スコアとマルチプライヤーによる達成感
- 「もう少しだけ」と思わせる絶妙な難易度
- ページ離脱時の警告メッセージ

## 技術的な特徴

- Canvas不使用、純粋なCSS/JSによる実装
- マウス/タッチ追跡による視線の動き
- 段階的に追加される視覚効果
- 振動フィードバック対応（対応デバイス）
- レスポンシブデザイン
