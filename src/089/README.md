# Day 89: 矛盾を体現するもの

論理的な矛盾や逆説を視覚的・インタラクティブに体験できるウェブアプリケーションです。

## 矛盾の要素

### 1. 押せない押せるボタン
- 「押せません」と表示されているが押せる
- 押すたびにテキストが変わる
- 時々逃げる、時々押せなくなる

### 2. 見えない見えるテキスト
- 「見えません」と書かれているが見える
- 定期的に透明度が変化
- マウスオーバーで逆の動作

### 3. 止まっている動く要素
- 「静止しています」と表示しながら回転
- 内部要素は逆回転で相殺
- クリックで「止める」と加速

### 4. 真実の嘘
- 「この文章は嘘です」という自己言及パラドックス
- 真実と嘘が交互に入れ替わる
- クリックで一時的に「どちらでもある」状態

### 5. 満ちている空のプログレスバー
- 視覚的には満ちているが数値は0%
- 進行と逆行が同時に起こる
- 完了率の矛盾した表示

### 6. 音のない音
- 無音を「再生」するボタン
- 視覚的なフィードバックのみ
- 振動で音を表現（対応デバイス）

### 7. 選択できない選択肢
- ラジオボタンが選択を拒否
- 選ぼうとすると別の選択肢が選ばれる
- すぐに選択が解除される

### 8. シュレーディンガーの箱
- 開いているが閉じている状態
- 観測しても状態が確定しない
- 中身が常に変化する

## その他の矛盾

- **見えないカーソル**: 実際の位置と異なる場所に表示
- **ページの存在**: 時々「存在しない」と主張
- **背景の反転**: 白と黒が入れ替わる
- **コンソールログ**: 矛盾したメッセージ

## 技術的な実装

- 純粋なJavaScript/CSS/HTMLで実装
- 視覚と論理の不一致を演出
- ユーザーの期待を裏切るインタラクション
- モバイル対応
