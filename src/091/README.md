# Day 91: 完璧に不完全なもの

完璧さの中にある微細な不完全さが、真の美しさを生み出すことを体験するインタラクティブアートです。

## コンセプト

「侘び寂び」の精神に基づき、完璧すぎるものよりも、わずかな不完全さを含むものの方が美しいという考えを表現しています。各要素は99%以上完璧ですが、その1%未満の不完全さが全体に生命を与えています。

## 要素

### 1. 完璧な円（99.7%）
- ほぼ完璧な円だが、微細な歪みが存在
- リアルタイムで変動する完璧度

### 2. 整列したグリッド（99.2%）
- 64個のセルのうち1つだけが1ピクセルずれている
- クリックで位置が変わる

### 3. 滑らかなグラデーション（99.5%）
- 256段階の中に1箇所だけ段差
- 「欠陥を見つける」ボタンで位置を表示

### 4. 規則的なパターン（98.9%）
- チェッカーボードパターンにわずかな乱れ
- 秩序とカオスのバランスを調整可能

### 5. 完璧なリズム（99.1%）
- 4つのビートのうち1つが10msずれる
- BPMが微妙に変動

### 6. 完全な対称性（99.0%）
- 左右対称だが、わずかなずれ
- スライダーで対称度を調整

### 7. 完璧な色彩調和（99.8%）
- 4色の調和的配色に2度のずれ
- ホバーで反応

### 8. 統一されたタイポグラフィ（99.3%）
- 1文字だけフォントサイズが0.5px違う

## インタラクション

- **総合完璧度**: すべての要素の平均値を表示
- **「完璧にする」ボタン**: 100%にすると逆に美しさが失われる
- **リアルタイムグラフ**: 各要素の完璧度を視覚化

## 技術的な特徴

- Canvas APIによる動的な図形描画
- CSSの微細な値（0.5px、0.1度など）の活用
- リアルタイムアニメーション
- インタラクティブな調整機能

## 哲学

完璧を追求しながらも、わずかな不完全さを許容することで、より人間的で美しいものが生まれることを示しています。
