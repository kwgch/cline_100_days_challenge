# Day 83: キモかわアートジェネレーター

キモさとかわいさを調整できる、独特なアートを生成するジェネレーターです。

## 機能

- **動的アート生成**: ランダムな形状と特徴を持つ生き物を生成
- **パラメータ調整**: 
  - キモさ度（0-100%）: 触手、不規則な形状、多数の目など
  - かわいさ度（0-100%）: 丸い形状、キラキラした目、ハートの装飾など
- **保存機能**: 生成したアートを画像として保存
- **シェア機能**: SNSなどでシェア（対応ブラウザのみ）
- **タッチ対応**: キャンバスをタップして再生成

## 技術的な実装

- Canvas APIを使用した動的な図形描画
- パラメータに基づいた生成アルゴリズム
- モバイル対応のレスポンシブデザイン
- タッチイベントへの対応

## 使い方

1. スライダーでキモさとかわいさのバランスを調整
2. 「生成する」ボタンで新しいアートを作成
3. 気に入ったら「画像を保存」でダウンロード
4. 「シェア」ボタンでSNSに投稿（対応環境のみ）
