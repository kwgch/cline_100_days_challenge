# Day 86: 適当すぎるミームジェネレーター

低クオリティで適当なミームを自動生成する、やる気のないミームジェネレーターです。

## 機能

- **適当な背景生成**: 単色、グラデーション、模様、図形、ノイズなどランダムに選択
- **自動テキスト生成**: よくあるミーム風の適当な文章を自動で配置
- **意図的な低品質化**: 
  - 画質を悪くする機能
  - 変なフォントを使う機能
  - ピクセレート効果
- **適当な装飾**: 絵文字、矢印、円などをランダムに追加
- **履歴機能**: 最近作った3つまでを表示（クリックで再利用）
- **保存機能**: JPEGで低品質保存
- **シェア機能**: 動作するかは運次第

## 技術的な特徴

- Canvas APIを使用した動的画像生成
- わざと悪いデザインを実現
  - Comic Sans MSフォント優先
  - 虹色グラデーション背景
  - 要素の微妙な傾き
- モバイル対応（一応）

## 使い方

1. 「てきとうに作る」ボタンを押す
2. 気に入らなければ何度でも押す
3. オプションで低品質化の調整
4. テキストは自動生成または手動入力
5. 保存してSNSで使う（推奨しません）
