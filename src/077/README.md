# 077: 4D Fractal Projection

4次元フラクタル図形を3次元空間に投影したインタラクティブWebGLアート作品です。複雑なUIを排除し、直感的なタッチ・スワイプ操作で4次元空間を探索できます。

## 機能

- **4次元フラクタル**: Julia集合、Mandelbulb、ハイブリッドモードの3種類
- **直感的な操作**:
  - タッチ/ドラッグ: 3D回転
  - ピンチ: ズーム
  - 2本指ドラッグ: パン
  - 3本指: 4D回転
- **リアルタイムレンダリング**: WebGL2によるレイマーチング
- **自動アニメーション**: 4次元空間での継続的な回転

## 技術詳細

- WebGL2 シェーダーによるレイマーチング
- 4次元から3次元への立体射影
- タッチイベントの高度な処理
- モバイル対応のレスポンシブデザイン
