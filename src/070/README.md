# 混乱UI - 操作するほど混乱するインターフェース

## 概要
このプロジェクトは、ユーザーが操作すればするほど混乱を招くUIを実装したWebアプリケーションです。通常のUIの常識を覆し、予期しない動作や混乱を招く要素を意図的に組み込んでいます。

## 混乱要素の特徴

### 1. ボタンの予期しない動作
- **ログインボタン**: ログインではなく、ログアウトしたり、画面を回転させたり、ボタン自体が逃げたりします
- **キャンセルボタン**: キャンセルではなく、データを保存したり、ファイルを削除する警告を出したりします
- **ヘルプボタン**: 役に立たないヘルプメッセージを表示し、時々消えます

### 2. 偽のUI要素
- **偽ボタン**: クリックしても何も起こらない、または予期しない動作をするボタン
- **偽の進捗バー**: 実際には何も処理していないのに進捗を表示

### 3. 動的な要素
- **逃げる要素**: クリックしようとすると逃げる、マウスオーバーで移動する要素
- **分裂する要素**: クリックすると複製される要素
- **消える要素**: 時間が経つと勝手に消えるボタン

### 4. 入力フィールドの混乱
- **文字の反転**: 入力した文字が勝手に逆順になる
- **パスワードの可視化**: パスワードフィールドが一時的にテキストになる
- **フォームの移動**: フォーカス時にフォーム全体が移動する

### 5. 混乱度システム
- 操作するたびに混乱度が上昇
- 混乱度が10を超えると画面全体がカオスモードに
- 混乱度が20を超えると画面が逆さまになる

### 6. ランダムイベント
- 定期的にランダムなイベントが発生
- ボタンのテキストが勝手に変わる
- 画面の色が変わる
- 偽のエラーメッセージが表示される

### 7. 邪魔な要素
- 画面に浮遊する邪魔な要素
- 閉じようとしても移動したり分裂したりする

## 技術仕様

### ファイル構成
```
src/070/
├── index.html    # メインのHTMLファイル
├── style.css     # スタイルシート（アニメーション含む）
├── script.js     # 混乱動作を制御するJavaScript
└── README.md     # このファイル
```

### 対応デバイス
- **PC**: マウス操作、キーボードショートカット対応
- **スマートフォン**: タッチ操作対応、画面移動防止機能付き

### 主要機能
1. **レスポンシブデザイン**: スマホとPCの両方で動作
2. **タッチ操作対応**: スマホでのタップ操作に対応
3. **画面移動防止**: `touch-action: manipulation`でスマホでの意図しない画面移動を防止
4. **アクセシビリティ**: 基本的なキーボード操作（ただし混乱を招く動作付き）

## 混乱を招く仕組み

### CSS アニメーション
- 背景のグラデーション変化
- 要素の浮遊、回転、拡大縮小
- 色の変化、透明度の変化

### JavaScript イベント
- クリック、ホバー、フォーカスイベントの予期しない処理
- ランダムな要素の移動と変更
- タイマーベースの自動イベント

### ユーザー体験の破綻
- 一般的なUI/UXの常識を意図的に破る
- ユーザーの期待と異なる動作
- 操作するほど状況が悪化する設計

## 使用方法
1. `index.html`をブラウザで開く
2. 各種ボタンや入力フィールドを操作する
3. 混乱度が上がるのを観察する
4. カオスモードを体験する

## 注意事項
- このUIは教育・実験目的で作成されています
- 実際のプロダクトでは使用しないでください
- 長時間の使用は混乱を招く可能性があります
- 画面酔いしやすい方は注意してください
