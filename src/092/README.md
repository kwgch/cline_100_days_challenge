# Day 92: 動かない動きを表現して

静止と運動の境界を探求し、動いていないのに動きを感じさせる視覚的パラドックスを体験するインタラクティブアートです。

## 表現された概念

### 1. ゼノンの矢
- 飛んでいる矢は各瞬間において静止している
- 連続した静止画が動きの軌跡を表現
- 時間の離散的な表現

### 2. 静止した軌跡
- マウスの動きに追従する残像効果
- 物体自体は動かないが、痕跡が動きを暗示
- 視覚的持続性の利用

### 3. 断続的な静止
- ストロボ効果による離散的な位置変化
- 瞬間移動のような非連続的な「動き」
- アニメーションの原理

### 4. 振動する静止
- 静止パターンによる視覚的振動錯視
- チェッカーボードパターンの微細な角度変化
- 物理的静止と知覚的振動の乖離

### 5. ぼやけた静止
- モーションブラーだけが存在する状態
- 動きの暗示のみで実際の動きはない
- 速度の視覚的表現

### 6. 相対的な不動
- 回転する参照フレームと逆回転する物体
- 観測者に対して静止、空間に対して運動
- 相対性の概念

### 7. 凍結した瞬間
- 同じ時刻を表す複数の表現
- 時間は止まっているが表現は変化
- 時間のスライス

### 8. 内在する動き
- ポテンシャルエネルギーの視覚化
- 今にも動き出しそうな緊張状態
- 静的な動的平衡

## 技術的な特徴

- Canvas APIによる視覚効果
- CSSアニメーションの巧妙な利用
- 知覚できない微細な動き（0.1px単位）
- 視覚的錯覚の活用
- リアルタイムインタラクション

## インタラクション

- **マウス追従**: 残像効果の生成
- **自動アニメーション**: 各要素が独自のタイミングで「静止」
- **動き度メーター**: 知覚される動きの量を可視化
