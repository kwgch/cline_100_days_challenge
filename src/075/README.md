# Day 075 - 時空無視アートジェネレータ | Timeless Space Art Generator

時間と空間の概念を超越したアートを生成するジェネレーティブアートアプリケーション。

## 機能

### 生成モード
1. **フラクタル次元** - ジュリア集合をベースにした時空歪曲フラクタル
2. **波動関数** - 量子波動の干渉パターン
3. **粒子雲** - 多次元粒子システム
4. **超弦理論** - 振動する弦の視覚化
5. **虚空結晶** - 幾何学的な結晶構造

### パラメータ
- **次元密度**: 生成される要素の複雑さ
- **時間歪曲**: 時間軸に沿った変化の速度
- **空間折り畳み**: 空間の曲率と折り畳み
- **量子揺らぎ**: ランダム性とカオス度
- **色彩次元**: 色空間の選択（RGB、HSV、量子、超次元）

### 時空メトリクス
- 時間位相の追跡
- 空間曲率の計算
- 次元交差イベント
- エントロピー測定

## 技術詳細

### アルゴリズム
- ジュリア集合フラクタル生成
- 正弦波干渉パターン
- 極座標系粒子配置
- 多次元振動シミュレーション
- 幾何学的結晶成長アルゴリズム

### 実装
- Canvas 2D APIによる描画
- リアルタイムアニメーション
- 動的パラメータ調整
- 画像保存機能

## 使用方法

1. 生成モードを選択
2. スライダーでパラメータを調整
3. 「生成」ボタンで新しいアートを作成
4. 「時空変動」でアニメーション開始
5. 「保存」で画像をダウンロード

時間と空間の制約を超えた、無限の可能性を持つアート体験をお楽しみください。
