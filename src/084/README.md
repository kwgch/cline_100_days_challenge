# Day 84: 絶対にバズらない投稿文ジェネレーター

SNSで誰も反応しない、究極に退屈な投稿を自動生成するツールです。

## 機能

- **プラットフォーム対応**: Twitter、Instagram、Facebook、LinkedInに対応
- **退屈度調整**: 1〜10のスライダーで退屈さをコントロール
- **多彩な退屈パターン**:
  - 日常の些細すぎる出来事
  - 誰も興味がない個人的な詳細の羅列
  - 意味のない技術的な内容
- **架空のエンゲージメント表示**: 退屈度に反比例する「いいね」数
- **コピー機能**: 生成した投稿をワンクリックでコピー
- **バズらないコツ**: 効果的に無視される投稿のヒント表示

## 技術的な特徴

- テンプレートベースの文章生成システム
- プラットフォーム別の文体再現
- 退屈度に応じた無駄な要素の自動追加
- モバイル対応のレスポンシブデザイン

## 使い方

1. プラットフォームを選択
2. 退屈度をスライダーで調整（高いほど退屈）
3. 「退屈な投稿を生成」ボタンをクリック
4. 生成された投稿をコピーして実際のSNSに投稿（推奨しません）
