# Day 082: 診断メーカー風ジェネレーター

診断メーカー風の診断ジェネレーターです。オリジナルの診断を作成して、楽しく遊べます。

## 機能

- **診断作成機能**
  - タイトル、入力項目、結果テンプレートの設定
  - 複数の結果パターンの登録
  - 診断の保存（ローカルストレージ）

- **診断実行機能**
  - 保存された診断の実行
  - 入力値に基づく結果の生成
  - 結果のシェア機能

- **デフォルト診断**
  - 動物診断
  - オーラカラー診断

## 使い方

1. **診断を作成する**
   - 診断タイトルを入力
   - 入力項目の名前を設定（例：名前）
   - 結果テンプレートを編集
   - 結果パターンを追加

2. **診断を実行する**
   - 保存された診断から選択
   - 入力項目に入力
   - 診断結果を確認

3. **結果をシェア**
   - シェアボタンで結果を共有
   - クリップボードにコピー

## 技術仕様

- 純粋なJavaScript（フレームワーク不使用）
- LocalStorageでデータ永続化
- レスポンシブデザイン
- モバイル最適化
