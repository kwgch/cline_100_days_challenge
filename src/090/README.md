# Day 90: 存在しないものを存在させて

存在しない概念、形、色、音、時間などを視覚化し、体験可能にするインタラクティブアートです。

## 存在しない要素

### 1. 不可能な形状
- ペンローズの三角形のような視覚的パラドックス
- 存在レベルに応じて変化する形状
- 3次元では不可能な接続

### 2. 存在しない色
- 可視光スペクトラム外の「色」
- octarine、vantablack-white、ulfire、jale などの架空の色名
- 複数の色の重ね合わせによる表現

### 3. 無音の騒音
- 音のない音を視覚化
- 負の周波数という概念
- 振動による触覚的な「音」の体験

### 4. 読めない文字の詩
- Unicode私用領域や結合文字を使用
- 意味を持たない文字列による詩
- ホバーで更に読めなくなる

### 5. 存在しない時間
- 逆行する時計
- 13時間制、100分制
- 存在しない針の動き

### 6. 忘れられた記憶
- 体験したことのない記憶の断片
- 一時的に現れて消える
- 思い出せないものを思い出すボタン

### 7. 影のパラドックス
- 影のない物体
- 物体のない影
- マウス位置と逆方向に動く影

### 8. 存在しない空間
- 内側でも外側でもない場所
- クラインの壺的な空間の歪み
- 3次元と4次元の間

## インタラクション

- **存在レベル**: 0%から100%まで変動するページの存在度
- **マニフェストボタン**: 存在/非存在を切り替え
- **自然な変動**: 存在レベルが自動的に揺らぐ
- **視覚効果**: 存在レベルに応じた透明度やエフェクト

## 技術的な特徴

- Canvas APIによる不可能図形の描画
- CSS3Dトランスフォームによる空間の歪み
- Web Vibration APIによる触覚フィードバック
- Unicode私用領域の活用
- パーティクルシステムによる存在の視覚化
