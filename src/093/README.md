# Day 93: 見えない色を使って何か作って

人間の知覚を超えた「見えない色」を探求し、体験可能な形で表現するインタラクティブアートです。

## 見えない色の種類

### 1. 紫外線スペクトラム
- 蜂が見ている花の紫外線模様
- 人間の視覚と蜂の視覚の比較
- ネクターガイド（蜜標）の可視化

### 2. 赤外線ビジョン
- 蛇が感じる熱の分布を色で表現
- ヒートマップによる温度の可視化
- 感度調整可能な熱画像

### 3. 不可能な色
- 赤緑色（reddish-green）
- 黄青色（yellowish-blue）
- 対立色を同時に知覚する試み

### 4. 補色残像
- 30秒間の凝視で生まれる残像
- 存在しない色が脳内で生成される現象
- 補色の自動生成

### 5. 四色覚の世界
- 通常の3原色（RGB）に第4の原色を追加
- 4次元色空間の3次元投影
- テトラクロマット（四色型色覚）の体験

### 6. 共感覚：音の色
- 周波数を色彩に変換
- 220Hz〜880Hzの音域を視覚化
- 音の振動を色のグラデーションで表現

### 7. 感情の色彩
- 喜び、悲しみ、怒り、恐れ、愛の色
- 心理的な色の知覚
- 感情に応じた色のパターン生成

### 8. 暗黒より暗い色
- ベンタブラック（光を99.965%吸収）
- 視覚的な「穴」の表現
- 限界を超えた暗さの追求

## インタラクション

- **フィルター切り替え**: 異なる生物の視覚体験
- **スライダー操作**: 感度や次元の調整
- **ボタン操作**: 色の生成や知覚の変更
- **長時間凝視**: 残像効果の体験

## 技術的な実装

- Canvas APIによる動的な色生成
- Web Audio APIによる音と色の連携
- CSSグラデーションとフィルター効果
- 視覚的錯覚の活用

## 色彩理論の拡張

このプロジェクトは、可視光スペクトラムの外側にある色、物理的に不可能な色、心理的・感情的な色など、通常の色彩理論を超えた領域を探求しています。
