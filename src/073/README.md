# カンバンタスクゲーム

## 概要
カンバンボードを使ったシンプルなタスク管理ゲームです。Doingカラムにランダムにタスクが追加され、それらをクリックしてDoneカラムに移動させることでタスクを完了させます。

## ゲームの流れ
1. Doingカラムにタスクが自動的に追加されます
2. タスクをクリックするとDoneカラムに移動します
3. Doneカラムのタスクは一定時間後に自動的に消えます
4. 10個のタスクを完了すると紙吹雪でクリア演出が表示されます

## 機能
- **自動タスク生成**: 2-5秒間隔でランダムにタスクが生成されます
- **タスク移動**: DoingからDoneへのワンクリック移動
- **自動削除**: Doneのタスクは2-4秒後に自動削除
- **クリア演出**: 目標達成時の紙吹雪アニメーション
- **レスポンシブデザイン**: スマホ・PC両対応
- **タッチ最適化**: スマホでの操作性を重視

## 技術仕様
- HTML5 Canvas（紙吹雪アニメーション）
- CSS Grid Layout（レスポンシブ対応）
- ES6 Classes（ゲームロジック）
- CSS Animations（タスク移動・削除エフェクト）

## 操作方法
- **PC**: マウスクリックでタスクを移動
- **スマホ**: タップでタスクを移動
- **新しいゲーム**: 「新しいゲーム」ボタンでリスタート
