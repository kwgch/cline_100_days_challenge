# Day 079 - X.com UI Clone

X.com（旧Twitter）のユーザーインターフェースを再現した静的なWebページです。

## 機能

- X.comライクなダークテーマのデザイン
- サイドバーナビゲーション
- ポスト投稿フォーム（見た目のみ）
- タイムライン表示
- 右サイドバー（トレンド・おすすめユーザー）
- レスポンシブデザイン対応

## 技術スタック

- HTML5
- CSS3（Flexbox、Grid）
- SVGアイコン

## 注意事項

このプロジェクトは見た目だけの実装で、実際の機能はありません。
ボタンやリンクをクリックしても動作しません。
