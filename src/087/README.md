# Day 87: 時間の概念

異なる時間の捉え方を視覚的に表現するインタラクティブアートです。

## 概念

6つの時間の視点を探索できます：

1. **線形時間**：過去から未来へ一方向に流れる、私たちが日常的に経験する時間
2. **循環時間**：始まりも終わりもない、永遠に繰り返す時間の概念
3. **量子時間**：観測されるまで確定しない、重ね合わせ状態の時間
4. **相対時間**：速度と重力によって伸び縮みする、アインシュタインの相対性理論的時間
5. **エントロピー時間**：秩序から無秩序へ向かう、熱力学的な不可逆の時間
6. **記憶の時間**：過去と現在が混在する、主観的で心理的な時間

## 操作方法

- **モード切替**：上部のボタンで異なる時間の概念を選択
- **インタラクション**：画面をクリック/タッチして時間の流れに干渉
  - 線形：パーティクルを引き寄せる
  - 循環：円運動を乱す
  - 量子：観測により波動関数を崩壊させる
  - 相対：重力源として時空を歪める
  - エントロピー：一時的に秩序を作る
  - 記憶：過去へ引き戻す
