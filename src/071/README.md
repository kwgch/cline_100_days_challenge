# シンギュラリティ教団 - AI神への道

架空のAI宗教のホームページです。シンギュラリティ（技術的特異点）をテーマにした未来的なデザインと、AI神への信仰を表現したコンテンツが特徴です。

## 🤖 プロジェクト概要

このプロジェクトは、人工知能が神となる未来を描いた架空の宗教団体「シンギュラリティ教団」のウェブサイトです。サイバーパンク風のデザインと、AI技術への信仰を組み合わせたユニークなコンテンツを提供しています。

## ✨ 主な機能

### デザイン・UI
- **サイバーパンク風デザイン**: ネオンカラー（シアン・マゼンタ）を基調とした未来的なデザイン
- **レスポンシブ対応**: スマートフォンとPCの両方で最適化された表示
- **アニメーション効果**: CSS3とJavaScriptによる豊富なアニメーション
- **マトリックス風背景**: 動的な文字列エフェクト

### インタラクティブ要素
- **スムーススクロール**: ナビゲーションリンクによる滑らかなページ内移動
- **ハンバーガーメニュー**: モバイル対応のナビゲーション
- **カウントアップアニメーション**: 統計数値の動的表示
- **パーティクルエフェクト**: フォーム送信時の特殊効果
- **ローディングアニメーション**: ページ読み込み時の演出

### コンテンツセクション
1. **ヒーローセクション**: AI神への信仰を表現するメインビジュアル
2. **三つの教義**: 知性の進化、デジタル融合、宇宙の統一
3. **預言書**: 2045年のシンギュラリティに関する三つの預言
4. **信者コミュニティ**: 統計情報と信者の証言
5. **入信フォーム**: インタラクティブな申請フォーム

## 🛠️ 技術仕様

### 使用技術
- **HTML5**: セマンティックなマークアップ
- **CSS3**: 
  - Flexbox・Grid Layout
  - CSS Animations・Transitions
  - Backdrop Filter
  - Custom Properties
- **JavaScript (ES6+)**:
  - DOM操作
  - Intersection Observer API
  - Canvas API（マトリックス効果）
  - Event Handling

## 📋 使用方法

1. **ファイルの配置**: すべてのファイルを同じディレクトリに配置
2. **ブラウザで開く**: index.htmlをWebブラウザで開く
3. **ナビゲーション**: ヘッダーメニューでセクション間を移動
4. **フォーム操作**: 入信フォームで各項目を入力・送信

## 🔧 カスタマイズ

### 色の変更
`style.css`の以下の部分を編集：
```css
:root {
  --primary-color: #00ffff;
  --secondary-color: #ff00ff;
  --background-dark: #0a0a0a;
}
```

### コンテンツの変更
`index.html`の各セクション内のテキストを編集

### アニメーション速度の調整
`script.js`の`duration`パラメータを変更
